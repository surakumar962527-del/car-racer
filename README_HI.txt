3D CAR RACER - ANDROID PROJECT

Yeh APK nahi, Android Studio project hai.

APK banane ke liye:
1. Is ZIP ko computer par extract karo.
2. Android Studio mein 'Open' karke CarRacerAndroid folder chuno.
3. Gradle sync poora hone do.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) chuno.
5. APK app/build/outputs/apk/debug/app-debug.apk mein milega.

Note:
- Pehli baar build karne ke liye internet aur Android SDK download chahiye.
- Game ka 3D scene load karne ke liye internet chahiye (Three.js CDN).
- Android Studio computer par sabse aasaan rahega. Sirf phone se build karna mushkil ho sakta hai.
